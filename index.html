Домашнє завдання: псевдоелементи та z-index

Практичні завдання на застосування псевдоелементів (::before, ::after), керування шарами та створення Stacking Context.

ЧАСТИНА 1 Завдання 1. Декоративні стилі через псевдоелементи

1.1. Кастомні стилізовані лапки для цитати (<blockquote>)

Базовий
  • Створіть в HTML стандартний тег <blockquote> із довільним текстом цитати.
  • За допомогою псевдоелемента ::before додайте відкриваючу лапку " перед текстом.
  • За допомогою псевдоелемента ::after додайте закриваючу лапку " після тексту.
  • Вимоги до стилізації: Лапки повинні мати збільшений розмір (font-size: 3rem або 4rem), акцентний колір, напівпрозорість (opacity: 0.4) та не порушувати базовий рівень цитати.
Найкращий спосіб вивчити CSS — створювати щось власноруч.

1.2. Інтерактивна кнопка зі стрілкою

Базовий
  • Створіть кнопку <button class="btn">Дізнатися більше</button>.
  • Через псевдоелемент ::after додайте символічну стрілку після тексту кнопки.
  • Налаштуйте плавний рух стрілки: при наведенні курсора стрілка має зміщуватися вправо на 6px за допомогою transform: translateX(6px) та transition.

ЧАСТИНА 2 Завдання 2. Керування шарами та z-index

Картка товару або статті з бейджем та затемненням (Overlay)

Середній
  • Створіть контейнер картки <div class="card"> із зображенням, заголовком, описом та бейджем <span class="badge">New</span>.
  • Позиціонування бейджа: надайте картці position: relative. Бейдж розмістіть у верхньому лівому куті за допомогою position: absolute, top: 10px, left: 10px. Встановіть z-index: 10, щоб бейдж гарантовано залишався поверх фото.
  • Затемнення при наведенні: створіть темний overlay за допомогою .card::before та background: rgba(0, 0, 0, 0.5), який при наведенні покриває 100% площі картки.
  • Контекст накладання: переконайтеся, що текст та кнопка залишаються читабельними поверх затемнення за рахунок правильного налаштування position: relative та вищого значення z-index.

ЧАСТИНА 3 Завдання 3. Мініпроєкт: Анімований фоновий шар

Інтерактивна картка з ефектом заповнення фону (z-index: -1)

Просунутий
  • Створіть картку .interactive-card з білим фоном, темним текстом та чіткою рамкою.
  • Фоновий псевдоелемент: створіть .interactive-card::before абсолютно позиціонованим фоновим шаром. Використайте z-index: -1, щоб псевдоелемент знаходився під усіма елементами картки.
  • Обмеження меж: задайте для картки position: relative та overflow: hidden.
  • Анімація появи: початково приховайте псевдоелемент за допомогою transform: scaleX(0) або left: -100%. При :hover він має плавно розгортатися на 100% ширини за допомогою transition.
  • Контрастність тексту: при наведенні текст та заголовок картки повинні плавно змінювати колір для забезпечення високої читабельності.
